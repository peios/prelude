# Archived Pekit Recipes

These recipes record Prelude at commit
`75c909adf61c52f04efa8a23759f9e513570474a`, before the Bazel migration.
They are historical inputs, not supported build commands. Relative paths
refer to their original repository locations. Use `docs/building.md` for
the maintained build and PPK workflow.

The obsolete Cargo vendor snapshot remains in the original repository and
in Git history. The maintained dependency graph is pinned by Cargo.lock,
MODULE.bazel, and MODULE.bazel.lock. The PPK writer has its own recorded
snapshot under `vendor/ppk/`.
